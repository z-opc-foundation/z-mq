## 3. 等谁拍什么（"排产归属"三问）

1. **导出面放在哪**：broker 自己开一个只读 HTTP 口（像 z-graph 的 `GraphControlServer` 那样用 JDK `HttpServer`），
   还是由已有的 `z-mq-broker-admin`（Spring Boot，`:9090`）代理过去？
   后者要新增一个 broker 侧的**只读命令字**（协议面改动），前者不改协议但要让 broker 多一个监听口。
2. **feeder 接哪些指标**：现有 `BrokerMetrics` 里有哪几类计数（发送/拉取/位点/存储）？
   要不要把 `SendMessageProcessor` 那个私有 `TopicLogHelper` 的两个计数器并进来（否则两套计数各数各的）。
3. **要不要 Grafana dashboard**：仓里现在**没有**任何 dashboard 文件；这一问决定本票的交付面到哪。
